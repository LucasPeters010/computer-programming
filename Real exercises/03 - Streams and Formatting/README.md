# Streams and Formatting

Work in the order shown below. The level is relative to this category; an easy BST task can be harder than an easy class task.

| Exercise | Level | Focus |
|---|---|---|
| [Line Score Summary](01%20-%20Easy%20-%20Line%20Score%20Summary/README.md) | Easy | Parse named score lines and produce a precisely formatted summary through supplied streams. |
| [Invoice Formatter](02%20-%20Medium%20-%20Invoice%20Formatter/README.md) | Medium | Read a small delimited format and print aligned invoice rows using integer cents. |
| [Run Length Archive](03%20-%20Medium%20-%20Run%20Length%20Archive/README.md) | Medium | Encode text and decode a strict textual archive format without losing spaces or newline characters. |
| [Quoted Record Parser](04%20-%20Hard%20-%20Quoted%20Record%20Parser/README.md) | Hard | Implement a small state-based parser for records containing quoted fields and escaped quotes. |
