# Streams and Formatting

Work in the order shown below. The level is relative to this category; an easy BST task can be harder than an easy class task.

| Exercise | Level | Focus |
|---|---|---|

| [Simple Receipt](02%20-%20Medium%20-%20Simple%20Receipt/README.md) | Medium | Read several valid records and calculate totals. |
| [Parse a Booking Line](03%20-%20Medium%20-%20Parse%20a%20Booking%20Line/README.md) | Medium | Validate one record and write results through reference parameters. |
| [Small Command Reader](04%20-%20Hard%20-%20Small%20Command%20Reader/README.md) | Hard | Parse a tiny command language with exact output. |
