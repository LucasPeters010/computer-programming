# Dynamic Memory and Resizing

Work in the order shown below. The level is relative to this category; an easy BST task can be harder than an easy class task.

| Exercise | Level | Focus |
|---|---|---|
| [Owned Number Buffer](01%20-%20Easy%20-%20Owned%20Number%20Buffer/README.md) | Easy | Implement a small owning array class with checked access and overlapping shifts. |
| [Resizable Integer Vector](02%20-%20Medium%20-%20Resizable%20Integer%20Vector/README.md) | Medium | Extend a dynamic array with separate logical size and allocated capacity, close to the Library MyVector assignment. |
| [Editable Dynamic Sequence](03%20-%20Medium%20-%20Editable%20Dynamic%20Sequence/README.md) | Medium | Implement insertion and erasure while handling both unused capacity and allocation growth. |
| [Deep Copy Matrix](04%20-%20Hard%20-%20Deep%20Copy%20Matrix/README.md) | Hard | Build a resizable two-dimensional object that owns one allocation and remains independent when copied. |
