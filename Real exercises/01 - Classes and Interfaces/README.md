# Classes and Interfaces

Work in the order shown below. The level is relative to this category; an easy BST task can be harder than an easy class task.

| Exercise | Level | Focus |
|---|---|---|
| [Reservable Study Room](01%20-%20Easy%20-%20Reservable%20Study%20Room/README.md) | Easy | Implement a room that stores non-overlapping bookings. The challenge is maintaining a valid object state across several operations. |
| [Warehouse Orders](02%20-%20Medium%20-%20Warehouse%20Orders/README.md) | Medium | Design two cooperating classes that reserve and release stock without letting quantities become inconsistent. |
| [Course Gradebook](03%20-%20Medium%20-%20Course%20Gradebook/README.md) | Medium | Represent weighted assessments and a collection of students using a stable class interface. |
| [Train Seat Reservations](04%20-%20Hard%20-%20Train%20Seat%20Reservations/README.md) | Hard | Build a reservation model in which a booking may cover several consecutive seats and cancellation restores availability. |
