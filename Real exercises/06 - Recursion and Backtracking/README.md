# Recursion and Backtracking

Work in the order shown below. The level is relative to this category; an easy BST task can be harder than an easy class task.

| Exercise | Level | Focus |
|---|---|---|
| [Recursive Run Compression](01%20-%20Easy%20-%20Recursive%20Run%20Compression/README.md) | Easy | Use recursion to summarize consecutive equal values and to find the longest run. |
| [Exact Sum Selections](02%20-%20Medium%20-%20Exact%20Sum%20Selections/README.md) | Medium | Generate every index selection whose values total a target using recursive choices. |
| [One Route Through a Grid](03%20-%20Medium%20-%20One%20Route%20Through%20a%20Grid/README.md) | Medium | Find a route through a maze-like grid using recursive backtracking, similar to the Library path-finding task. |
| [Smallest Coin Selection](04%20-%20Hard%20-%20Smallest%20Coin%20Selection/README.md) | Hard | Search combinations with limited inventory and choose the best valid solution with a deterministic tie rule. |
