# Recursion and Backtracking

Work in the order shown below. The level is relative to this category; an easy BST task can be harder than an easy class task.

| Exercise | Level | Focus |

| [Recursive Binary Search](02%20-%20Medium%20-%20Recursive%20Binary%20Search/README.md) | Medium | Use recursion to choose one half of a sorted range. |
| [Can a Subset Reach the Target](03%20-%20Medium%20-%20Can%20a%20Subset%20Reach%20the%20Target/README.md) | Medium | Practise two recursive branches without constructing or ranking solutions. |
| [Find Any Grid Route](04%20-%20Hard%20-%20Find%20Any%20Grid%20Route/README.md) | Hard | Use the Library-style backtracking idea for one small search. |
